# Python Programming – Assignment 2 (CO2)

## 📘 Assignment Overview

This assignment focuses on Python programming concepts related to control flow, string manipulation, functions, recursion, validation, and program redesign. It includes seven tasks that demonstrate the use of Python concepts through practical problem-solving.

## 🎯 Objectives

- Understand and implement conditional statements.
- Use loops to control program execution.
- Perform string manipulation and formatting.
- Understand functions, arguments, return values, and scope.
- Explore recursion and memoization.
- Analyze program behavior and improve code design.
- Validate inputs and handle boundary conditions.

## 📂 Assignment Tasks

| Task | Topic | Concepts Used |
|---|---|---|
| Q1 | Decisions with Many Boundaries | Conditional statements, `if`, `elif`, `else` |
| Q2 | Loops that Count Attempts | `while`, `for`, `break`, `continue` |
| Q3 | Vehicle Registration Validator | Strings, slicing, validation |
| Q4 | Building Long Text | String concatenation, `join()`, formatting |
| Q5 | Functions, Parameters and Scope | Functions, arguments, return values, scope |
| Q6 | Recursion and Its Limits | Recursion, memoization, performance |
| Q7 | Diagnose, Redesign and Validate | Debugging, redesign, testing, optimization |

## ▶️ How to Run

1. Clone or download this repository.
2. Open the assignment folder in Visual Studio Code or Command Prompt.
3. Ensure Python is installed.
4. Run the required program using:

```bash
py filename.py
```

Replace `filename.py` with the name of the required Python file.

Example:

```bash
py A2_Q1_electricity_subsidy.py
```
